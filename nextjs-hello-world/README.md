## Recruiter demo

The `/admin` workspace is protected by default with HTTP Basic Auth. To make the
read-only workspace available for a recruiter-facing deployment, set this server
environment variable in Vercel:

```text
EDITORIAL_PUBLIC_DEMO=true
```

The deployment must also have `EDITORIAL_API_URL` and `EDITORIAL_API_KEY` set so
article reviews can load from the backend. Keep `EDITORIAL_API_KEY` server-only;
do not prefix it with `NEXT_PUBLIC_`. Leave `EDITORIAL_PUBLIC_DEMO` unset or set
it to `false` when the workspace should require login.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
